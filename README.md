# Event Management System Backend — MERN

A Event Management System Backend.

- `backend` — Node.js + Express + MongoDB/Mongoose

## Setup

### Backend
```bash
cd backend
npm install
copy .env.example .env
```

Edit `.env`:
```env
PORT=5000
MONGODB_URI=mongodb+srv://YOUR_USERNAME:YOUR_PASSWORD@YOUR_CLUSTER/event_management
JWT_SECRET=change_this_to_a_long_random_secret
```

Start:
```bash
npm run dev
```
